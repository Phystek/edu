Each stage's gain (Av1=×10, Av2=×100, Av3=×1) is fixed at the lecture's original values. What's adjustable here is every resistance — RS, each stage's own input resistance Ri and its output resistance Ro, and RL — so you can isolate exactly how much gain is lost purely to loading between stages, independent of the gain each stage is capable of.

Each stage's gain (Av1, Av2, Av3) is held fixed at the lecture's original values — shown in grey next to each dependent source on the diagram — so the sliders isolate purely resistive loading effects.
