Fortescue Decomposition Explorer

ELEC2005 · Week 9

Any unbalanced three-phase phasor set can be built from three balanced sets — zero, positive and negative sequence. Use Compose to build an unbalanced set from sequence components, or Decompose to extract the sequence components from a given unbalanced set — the two directions of the Fortescue transform.

A note on angle convention: textbooks vary. Glover's own definition of the sequence rotation operator uses 0–360° (e.g. a² = 1∠240°), but its worked examples often report specific values in whichever form is shortest — including negative angles (e.g. −120°). Both describe exactly the same phasor. Use the toggle below to match whichever convention you're working from — it only changes how angles are displayed, not the underlying values.
