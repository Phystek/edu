Phasors · Rotating-Vector Representation

The rms phasor V̄ = V∠δ (dashed maroon arrow) is a snapshot, at t = 0, of a vector rotating counter-clockwise at speed ω. It's always drawn in standard orientation, Re horizontal and Im vertical, matching the rest of this course. That never changes between the two modes below.

What changes is which function is plotted. In sine mode, the imaginary part is already vertical, so it connects straight across to the waveform. In cosine mode, this course's convention, the real part is horizontal, so it doesn't line up directly. The dashed line shows the real-axis projection first, then bends to reach the correct height.

Turn on the current phasor to see the same thing for Ī, and to see how φ = δ − β shows up as a lag or lead.

Why cosine mode's line bends: v(t) = √2V cos(ωt+δ) uses the real part of the rotating vector, and Re is horizontal in standard orientation. A waveform's value axis is always vertical, so the real part has to be converted first, which is what the bend shows. Sine mode doesn't need this, since Im is already vertical.
