Thyristors

Thyristor (SCR) State Explorer

ELEC2005 — Week 7

An SCR is a bistable, semi-controllable switch. Set the anode–cathode polarity and voltage, then try firing the gate. Notice that once conducting, the gate has no further effect — only reversing the polarity turns it off.

Simplified model: on-state voltage drop, holding current, and dV/dt-triggered false turn-on are not modelled. Turn-off is shown as immediate on polarity reversal; in a real circuit it depends on external commutation and the reverse-recovery interval.
