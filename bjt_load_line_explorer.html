Load Line Explorer

ELEC2005 · Week 3 companion

Drag VBB and watch the base loop set IB, which sets IC — and watch the Q-point slide along the collector loop's load line to match. Notice how flat the active region is: once VCE is high enough to reverse-bias the BC junction, IC stops changing with VCE and depends only on IB. Now try RC instead: in active mode it moves the load line and changes VCE, but IC stays exactly fixed — until RC gets large enough to push the same IB into saturation.
